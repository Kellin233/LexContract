# 📜 LexTrace

**合同与法律协议审查 Agent 系统**

面向条款分散、跨章节判断和证据难回溯的合同审查场景，生成基于原文、可复核的审查报告。

## 项目概述

LexTrace 接收用户提出的合同问题，在指定文档范围内查找相关条款，恢复完整上下文，校验引用来源，并输出带证据的结构化审查结果。系统把“找条款、做核验、下结论”拆开，确保最终结论能够回到合同原文，而不是只给出无法复查的模型回答。

**项目技术：** Python、asyncio、PostgreSQL、pgvector、BM25、bge-m3，以及统一的 OpenAI 兼容模型接口。

## 核心设计

### Agent 编排

系统采用“规划 → 并行取证 → 完整性复核 → 结论生成”的协作链路：

- **规划 Agent（Planner）：** 将用户问题拆成最多三个相互独立的调查要点，只描述需要查什么，不提前生成结论。
- **搜索 Agent（Searcher）：** 每个调查要点对应一个取证任务。多个任务通过 DAG 分层并行执行，Searcher 只返回候选证据，不负责解释合同或作出判断。
- **复核 Agent（Reviewer）：** 检查证据是否覆盖问题，识别明显冲突和信息缺口，只决定是否需要补查，不裁判冲突条款哪一条优先。
- **报告 Agent（Refiner）：** 读取已经校验的证据，生成唯一的最终结论、分点分析、引用和待确认事项。

证据充分时可以直接进入报告生成；证据不足时，系统根据 Reviewer 提出的缺口进行增量规划和补查。Searcher 由对象池管理，支持并发限制、任务超时，并对上下文异常的实例进行丢弃和重建。

### 搜索服务

合同入库时保留全文、章节层级、页码和字符位置。查询阶段采用向量检索与 BM25 关键词检索进行混合召回，并通过 Reciprocal Rank Fusion 合并候选结果。

Searcher 通过工具调用完成多轮取证：

1. 用语义检索查找同义表达和相关条款；
2. 用字面或正则匹配确认精确措辞、条款编号和交叉引用；
3. 按文档目录、章节或切片展开完整原文。

搜索和精确匹配默认只返回短片段用于定位，完整条款通过原文读取工具获取；查询始终受会话和文档范围约束，避免跨文档混淆证据。

### 证据处理与追溯

搜索结果首先作为候选切片，随后由系统按章节聚合为连续条款。证据的引用文本直接从文档全文的字符区间截取，模型不能改写、拼接或自行填写偏移量。

每条证据保存文档、章节、页码、字符范围和来源切片。进入报告前，程序会核对引用是否等于原文对应区间，并检查来源切片是否属于同一文档和章节、文本与位置是否一致；未通过校验的候选不会进入最终结果。

单次研究使用共享证据索引，按“文档 + 字符区间”去重并分配证据编号。不同环节通过证据编号关联同一份证据，需要分析时按索引读取原文，既减少重复上下文，又保留完整的回溯能力。报告中的每个引用都能还原到对应文档、章节、页码和原始文本。

## 评测结果

评测包含端到端合同分类和证据检索两部分。ContractNLI 衡量系统基于合同证据判断支持、矛盾或无法确定的能力；LegalBenchRAG 衡量 Searcher 找到的文档及字符区间与标注答案的重叠程度。引用有效性由程序规则直接核验。

| 评测任务 | 规模 | 结果 |
| --- | ---: | --- |
| ContractNLI | 150 条 | Accuracy **80.00%**；Weighted F1 **79.78%**；Contradiction / Entailment / Neutral F1：72.73% / 84.35% / 76.67% |
| LegalBenchRAG | 100 条 | 文档级 Precision / Recall **86.39% / 86.39%**；字符级 Span Recall **75.99%**；Span Precision 7.88%；Span F1 12.90% |
| 引用原文校验 | ContractNLI 233 条引用；LegalBenchRAG 200 条证据 | 均为 **100%** 通过 |

LegalBenchRAG 同时统计文档级和字符级指标：前者反映是否找到正确文档并覆盖相关文档，后者反映证据区间与标注区间的重叠。系统保留完整条款，因此在扩大覆盖范围的同时，字符级 Precision 会低于只返回最小片段的检索方式。

## 项目特点

- **原文驱动：** 结论和引用建立在合同原文之上，证据不能由模型改写。
- **职责分离：** 规划、取证、复核和结论生成各自承担单一职责。
- **混合检索：** 同时支持语义理解和关键词精确定位，适合处理条款同义表达、编号和交叉引用。
- **证据可回溯：** 引用关联文档、章节、页码和字符范围，支持逐条复核。
- **可控协作：** 支持并行任务、增量补查、检索轮次和上下文预算控制。
- **可评估：** 同时记录分类效果、证据覆盖、引用有效性和模型调用消耗。

## 适用场景

- 合同条款查询与要点提取
- 付款、交付、违约责任和终止条件审查
- 多份合同之间的义务、限制和风险对比
- 合规检查与法律研究辅助
- 带原文引用的合同问答和审查报告
